# Code of Conduct

This project expects technical discussion to remain respectful, specific, and safe.

## Expected behavior

- Review ideas and code without attacking the contributor.
- Distinguish verified runtime evidence from assumptions and static analysis.
- Protect user privacy by removing secrets and machine identifiers.
- Disclose compatibility risks and conflicts of interest.
- Accept correction when evidence changes.

## Unacceptable behavior

- Harassment, discrimination, threats, or personal attacks;
- publishing another person's private information;
- encouraging users to bypass authorization or test systems they do not control;
- knowingly submitting fabricated metrics, logs, security claims, or test results;
- repeatedly derailing technical work after a maintainer request to stop.

## Enforcement

Report conduct concerns privately through the repository's Security reporting channel when privacy is required. The maintainer may edit or remove content, close discussions, or restrict participation to protect contributors and users.
