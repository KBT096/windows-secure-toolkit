# Support

## Questions and ordinary defects

Use [GitHub Issues](https://github.com/KBT096/windows-secure-toolkit/issues) after checking the README and existing reports.

For users who do not want to build from source, the Releases page includes a versioned Windows x64 package. Please include the package version when reporting a problem.

Provide:

- toolkit version;
- Windows edition and build;
- whether the terminal was elevated;
- exact command;
- sanitized output and reproduction steps.

Do not post API keys, tokens, public IP addresses, usernames, organization names, full audit reports, or screenshots containing private data.

## Security issues

Follow [SECURITY.md](SECURITY.md) and use GitHub's private vulnerability reporting.

## Support boundary

The project cannot:

- recover access to locked or unmanaged systems;
- override organization policy or endpoint protection;
- certify compliance;
- guarantee compatibility with every legacy application;
- provide emergency incident response.

For managed or production devices, coordinate changes with the responsible administrator and maintain a separate tested recovery method.
